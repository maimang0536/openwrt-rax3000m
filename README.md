# RAX3000M OpenWrt 固件

## 📋 设备支持
- **RAX3000M EMMC 版** ✅
- **RAX3000M NAND 版** ✅

## ⚡ 核心功能
- **BBRv3 智能加速** - 谷歌最新拥塞控制算法
- **MTK 硬件加速** - 千兆 NAT 零 CPU 占用
- **Nginx 服务器** - 高性能 Web 服务支持
